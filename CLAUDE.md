# LILO Cosmetics — витрина корейской косметики (папка korshop-catalog)

Розничная витрина корейской косметики для покупателей из Бишкека, собрана из Excel-прайса склада.
Все действия ведут в WhatsApp: корзины и оформления заказа на сайте нет.

**Название магазина — LILO Cosmetics** (с 06.10.2026, бренд в `src/brand.ts` — менять только там;
Азиз в одном сообщении назвал и «Lilova Cosmetics», утверждённый вариант — LILO).
Репозиторий остался `azizatavaliev-bot/glowly`, Railway-проект `glowly`. Локальная папка —
`korshop-catalog`: на её `node_modules` симлинком завязан соседний KorProfit, не переименовывать.
Домен пока не куплен. Азиз хочет НЕ .kg (просил lilo.pro — занят с 2020). Проверено 06.10 через
RDAP + цены Porkbun: lilo.shop/.store/.online/.site — премиум ($137–546/год, не брать);
нормальные: lilo.asia $11.84/год, lilokorea.com / liloskin.com / lilokg.com $11.08/год,
lilocosmetics.pro $3.09 первый год → $22.14, lilo.care $11.84 → $39.65.
whois для новых зон врёт — проверять через https://rdap.org/domain/<имя> (404 = свободен) и цену у регистратора.
**Выбран lilo.asia** (06.10, Азиз: «разницы нет, главное чтобы сайт был»). В Railway уже заведены
custom domains: `lilo.asia` → CNAME/ALIAS @ на `e9jc6vlc.up.railway.app`, `www.lilo.asia` → CNAME www на
`lm6nz005.up.railway.app`. Осталось: Азиз покупает домен на Porkbun, вставляет две записи, ждём SSL.
lilo.space не подтверждён по цене (Porkbun показал капчу); соседние зоны Radix для «lilo» все премиум.
korshop.one — сайт склада-поставщика, в футере клиентской витрины его нет.

## Обновление прайса
1. Положить новый xlsx (по умолчанию `~/Desktop/прайс 8.09.xlsx`).
2. `python3 scripts/parse_price.py "путь/к/прайсу.xlsx"` — перезапишет `src/data/products.json` и докинет картинки в `public/img` (имя файла = md5 картинки, дубликаты не плодятся).
3. Нужны `openpyxl` и `Pillow`.

## Как устроен прайс
- Строка без цены = заголовок бренда или раздела «АКЦИЯ N% K/S» (K/S — похоже, склад; в бейдже буква срезается).
- Картинка товара приклеена к строке в колонке C, вытаскивается по anchor'у строки.
- Бренд берётся из скобок в конце названия, а не из строки-заголовка — так надёжнее.
- Категория определяется по ключевым словам в `category()` в парсере. Правишь правила — перегоняешь данные.

## Грабли
- Цены в xlsx строками с запятой («1,90») — парсятся через `num()`.
- Колонка «Сумма заказа» — формулы `=RC[-1]*RC[-3]`, их не читаем.
- `npm create vite` в непустой папке падает — конфиги здесь написаны руками.
- Скриншоты: `node scripts/shot.mjs` (desktop) и `scripts/shot-mobile.mjs`, dev-сервер должен быть запущен.

## Структура фронта
- `src/App.tsx` — состояние каталога, фильтры, корзина
- `src/components/Hero.tsx` — первый экран: градиентные пятна (`.blob`, анимация `drift`), подсветка
  за курсором через CSS-переменные `--mx/--my`, сменяющееся слово в заголовке (`.swap`), счётчики
  `useCountUp`, поиск с живыми подсказками и три ленты товаров с плашками `.float`
- `src/components/Marquee.tsx` — бегущая лента брендов, клик = фильтр по бренду
- `src/useReveal.ts` — появление блоков по `data-reveal` через IntersectionObserver
- Шрифты Manrope + Playfair Display подключены с Google Fonts (офлайн — откатятся на системные)

## Фото товаров
- В xlsx лежат превью 146 px — для сайта негодны.
- `scripts/fetch_photos.py` ищет фото по штрихкоду, качает оригиналы (≥1000 px), подписывает названием и складывает в `~/Desktop/Каталог KORSHOP/Фото`.
- `scripts/import_photos.py` переносит их в `public/photos` (webp 900 px) и пишет `photos[]` в products.json.
- `scripts/verify_photos.py` сверяет каждое фото с превью из прайса по цветовой гистограмме: явный мусор удаляет, остальные сортирует — самое похожее становится обложкой. Часть фото всё же может оказаться другим товаром того же бренда, проверять глазами.

## Цены
`src/pricing.ts` — единственное место, где считаются деньги:
`цена = прайс_$ × RATE(87.5) × RETAIL_K(1.42)`, округление до десятков сомов.
1.42 — это цена города (+58% к оптовой) минус 10%, чтобы мы всегда были дешевле магазина.
Рядом показываем зачёркнутую «цену города» и выгоду. **Курс проверять перед показом.**
Долларов на сайте нет нигде — покупатель видит только сомы.

**Топ-15** (`src/data/top.json`): владелец дал список из 15 позиций со своими ценами. Для них
`price()` возвращает цену из списка, а не формулу. Товар 566 (SKIN1004 Cleansing Oil) заведён
вручную — в прайсе склада его нет, при перегонке прайса парсером он **пропадёт**, добавлять заново.
Reedle Shot 100 из топа — это id 528 (флакон 50 мл), не саше 514–516.

**Витрина = только top.json.** С 30.09.2026 по решению Азиза на сайте показываются ТОЛЬКО эти 15
позиций по его ценам (`all = products.filter(inStock)` в App.tsx). Остальные 551 позиция прайса лежат
в products.json, но не рендерятся. Чтобы добавить товар на сайт — дописать его в top.json с ценой.

## Видеообзоры
`scripts/find_videos.py` ищет ролики на YouTube по «бренд + латинское название + обзор»,
берёт только те, где в заголовке есть бренд, слово из названия товара **и кириллица** —
англоязычные обзоры покупателю не нужны. Результат — `src/data/videos.json` (384 из 565). В карточке показывается превью
`i.ytimg.com/vi/<id>/hqdefault.jpg` со ссылкой на YouTube, без iframe.
Иногда попадается ролик про соседний продукт той же линейки — проверять выборочно.

## Поиск и полки
- `src/search.ts` — синонимы («прыщи» → acne/cica), английская раскладка (`rhtv` → крем),
  бренды кириллицей («анюа» → anua, «раунд лаб» → round lab), стоп-слова, обрезка окончаний.
  `score()` ранжирует: прямое совпадение в названии весит больше синонима. Ключи синонимов
  нужны с границами слова — «тон» без `\b` ловил «тонер» и выдавал осветляющие наборы.
- `src/needs.ts` — 12 полок «по задаче» вместо технических категорий, блок «Что вам нужно?».
- `src/name.ts` — делит название прайса на русскую часть (заголовок) и латиницу (подпись).

## Мобильная главная (основной сценарий — 98% трафика с телефона)
- Первый экран на телефоне: `.only-narrow` короткий текст, поиск, одна кнопка, `.stats-line` одной
  строкой вместо трёх крупных чисел. Декоративные `.lanes` скрыты, вместо них `.hero-rail` —
  настоящая лента «Хиты продаж» с ценами.
- `components/MobileBar.tsx` — нижняя панель (Каталог · Подбор · Избранное · Написать), показывается
  только до 720 px; на телефоне `.wa-fab` скрыт, `body` получает `padding-bottom: 58px`.
- `.top-search` — компактный поиск в шапке, появляется вместе с `.top.solid`; кнопка WhatsApp
  и сердечко при этом сжимаются до иконок.
- Поля ввода на телефоне ≥15px — иначе iOS зумит страницу при фокусе.
- **Грабли:** горизонтальная лента внутри грида раздувает колонку. Нужен `grid-template-columns:
  minmax(0, 1fr)` и `min-width: 0` у контейнера, иначе весь герой уезжает за правый край.

## Карточка товара
- `src/data/details.json` — описания 15 товаров, написанные руками: about, benefits, for, howto,
  actives, tip, result (что будет с кожей по неделям), combo, faq. Если товара нет в файле —
  карточка падает на генерируемые тексты из `describe.ts`.
- На телефоне модалка = отдельная страница: `.m-left { display: contents }` + order, фото листаются
  свайпом (`.m-swipe` + scroll-snap), внизу липкая `.m-buy` с ценой.
- **Грабли:** в flex-колонке модалки горизонтальная галерея схлопывается в ноль по высоте —
  нужен `flex: 0 0 auto` на `.m-swipe`, `.dots-nav`, `.m-body`, `.m-facts`.

## Фото витрины
`scripts/fetch_top_photos.py` — догрузка фото для товаров из top.json с жёсткой проверкой
(в имени файла/заголовке обязаны быть бренд и два слова из названия). `scripts/photo_sheet.py`
собирает контактный лист /tmp/sheet.jpg — проверять глазами, автопоиск подсовывает чужие бренды.

## Фишки для покупателя
- `src/store.ts` — избранное (`glowly.fav`) и «вы смотрели» (`glowly.recent`) в localStorage,
  синхронизация между компонентами через window-событие `store:<key>`.
- `components/RoutineBuilder.tsx` — конструктор ухода: 5 шагов (очищение → тонер → сыворотка → крем → SPF),
  кандидаты подбираются регулярками по типу шага, скорятся по задаче (NEEDS) и типу кожи. «Заменить» сдвигает offset.
  Регулярки шагов с исключениями — иначе кушон с «SERUM» в названии лезет в сыворотки.
- `components/FavPanel.tsx` — список избранного и заказ одним сообщением.
- Бейджи на карточке: «Выгодно» при экономии ≥150 с, «▶ обзор» если есть запись в videos.json.
- `public/manifest.webmanifest` + `icon.svg` — добавление на экран телефона.
- Фильтры пишутся в адрес (`?q=&need=&brand=&cat=&max=`) и читаются при загрузке — ссылка на
  подборку работает. Пока открыта карточка (`?p=`), фильтры в адрес не пишутся, чтобы не спорить за URL.
- `components/Toast.tsx` — уведомления через window-событие `glowly:toast`.
- Клавиша «/» фокусирует поиск каталога.

## Что умеет сайт
Поиск, фильтр по категории и бренду, сортировка, «только скидки», карточка товара
с пользой/аудиторией/инструкцией/видео, блоки «Почему мы», «Как заказать», FAQ.
Каждая кнопка «Заказать» открывает WhatsApp с готовым текстом: название, вариант, цена.
