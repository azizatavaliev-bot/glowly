# KORSHOP — каталог (korshop-catalog)

Розничная витрина корейской косметики для покупателей из Бишкека, собрана из Excel-прайса склада.
Все действия ведут в WhatsApp: корзины и оформления заказа на сайте нет.

## Стек
Vite 5 + React 18 + TypeScript, без бэкенда. Данные — статический `src/data/products.json`, картинки — `public/img/*.webp`. Корзина и курс валюты живут в localStorage.

## Обновление прайса
1. Положить новый xlsx (по умолчанию `~/Desktop/прайс 8.09.xlsx`).
2. `python3 scripts/parse_price.py "путь/к/прайсу.xlsx"` — перезапишет `src/data/products.json` и докинет картинки в `public/img` (имя файла = md5 картинки, дубликаты не плодятся).
3. Нужны `openpyxl` и `Pillow`.

## Как устроен прайс
- Строка без цены = заголовок бренда или раздела «АКЦИЯ N% K/S» (K/S — похоже, склад; в бейдже буква срезается).
- Картинка товара приклеена к строке в колонке C, вытаскивается по anchor'у строки.
- Бренд берётся из скобок в конце названия, а не из строки-заголовка — так надёжнее.
- Категория определяется по ключевым словам в `category()` в парсере. Правишь правила — перегоняешь данные.

## Грабли
- Цены в xlsx строками с запятой («1,90») — парсятся через `num()`.
- Колонка «Сумма заказа» — формулы `=RC[-1]*RC[-3]`, их не читаем.
- `npm create vite` в непустой папке падает — конфиги здесь написаны руками.
- Скриншоты: `node scripts/shot.mjs` (desktop) и `scripts/shot-mobile.mjs`, dev-сервер должен быть запущен.

## Структура фронта
- `src/App.tsx` — состояние каталога, фильтры, корзина
- `src/components/Hero.tsx` — тёмный первый экран, коллаж товаров с параллаксом за курсором
- `src/components/Marquee.tsx` — бегущая лента брендов, клик = фильтр по бренду
- `src/useReveal.ts` — появление блоков по `data-reveal` через IntersectionObserver
- Шрифты Manrope + Playfair Display подключены с Google Fonts (офлайн — откатятся на системные)

## Фото товаров
- В xlsx лежат превью 146 px — для сайта негодны.
- `scripts/fetch_photos.py` ищет фото по штрихкоду, качает оригиналы (≥1000 px), подписывает названием и складывает в `~/Desktop/Каталог KORSHOP/Фото`.
- `scripts/import_photos.py` переносит их в `public/photos` (webp 900 px) и пишет `photos[]` в products.json.
- `scripts/verify_photos.py` сверяет каждое фото с превью из прайса по цветовой гистограмме: явный мусор удаляет, остальные сортирует — самое похожее становится обложкой. Часть фото всё же может оказаться другим товаром того же бренда, проверять глазами.

## Цены
`src/pricing.ts` — единственное место, где считаются деньги:
`цена = прайс_$ × RATE(87.5) × RETAIL_K(1.42)`, округление до десятков сомов.
1.42 — это цена города (+58% к оптовой) минус 10%, чтобы мы всегда были дешевле магазина.
Рядом показываем зачёркнутую «цену города» и выгоду. **Курс проверять перед показом.**
Долларов на сайте нет нигде — покупатель видит только сомы.

## Видеообзоры
`scripts/find_videos.py` ищет ролики на YouTube по «бренд + латинское название + обзор»,
берёт только те, где в заголовке есть бренд, слово из названия товара **и кириллица** —
англоязычные обзоры покупателю не нужны. Результат — `src/data/videos.json` (384 из 565). В карточке показывается превью
`i.ytimg.com/vi/<id>/hqdefault.jpg` со ссылкой на YouTube, без iframe.
Иногда попадается ролик про соседний продукт той же линейки — проверять выборочно.

## Поиск и полки
- `src/search.ts` — синонимы («прыщи» → acne/cica), английская раскладка (`rhtv` → крем),
  бренды кириллицей («анюа» → anua, «раунд лаб» → round lab), стоп-слова, обрезка окончаний.
- `src/needs.ts` — 12 полок «по задаче» вместо технических категорий, блок «Что вам нужно?».
- `src/name.ts` — делит название прайса на русскую часть (заголовок) и латиницу (подпись).

## Что умеет сайт
Поиск, фильтр по категории и бренду, сортировка, «только скидки», карточка товара
с пользой/аудиторией/инструкцией/видео, блоки «Почему мы», «Как заказать», FAQ.
Каждая кнопка «Заказать» открывает WhatsApp с готовым текстом: название, вариант, цена.
